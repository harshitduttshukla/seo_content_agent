# Architecture Decision Records

ADRs capture decisions that constrain implementation. Status values are `proposed`, `accepted`, `superseded`, or `deprecated`. Changing an accepted decision requires a new ADR that links and supersedes it; edit an accepted ADR only to correct non-semantic errors.
